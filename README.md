## Dataset Balancing & Data Augmentation Pipeline

To address the severe class imbalance in the HAM10000 dataset (notably the overrepresentation of Melanocytic Nevi (`nv`) relative to rare classes like Dermatofibroma (`df`) and Vascular Lesions (`vasc`)), we implemented a combined **Undersampling + Oversampling / Data Augmentation** strategy.

### 1. Class Balancing Strategy
* **Target Count:** Standardized each disease category in the training set to **1,000 images**.
* **Undersampling (`nv` class):** Randomly sampled 1,000 images without replacement from the dominant `nv` class to prevent the network from developing a majority-class bias.
* **Oversampling (Minority classes):** Replicated original images and applied dynamic data augmentation pipeline transformations until each minority class (`akiec`, `bcc`, `bkl`, `df`, `mel`, `vasc`) reached 1,000 images.

### 2. Augmentation & Artifact Prevention
To ensure biological relevance without introducing boundary distortion artifacts:
* **Orthogonal Rotations ($90^\circ, 180^\circ, 270^\circ$):** Applied exact angle rotations.
* **Black Border Removal (`remove_black_borders`):** Automatically detects non-black bounding boxes using NumPy array masking to strip out black padding/margins generated by rectangular aspect ratio shifts.
* **Specular Inversions & Photometric Jitter:** Applied random horizontal/vertical flips and slight brightness/contrast/saturation variations (`ColorJitter`) to improve robustness against different camera/dermatology light settings.
* **Resizing:** Unified all augmented outputs to $224 \times 224$ pixels using bilinear interpolation, ready for direct ingestion by CNN/EfficientNet architectures.

### 3. File Structure & Workflow
* `balance_dataset.py`: Complete executable script that reads `HAM10000_metadata.csv`, processes images across `HAM10000_images_part_1` & `part_2`, and outputs clean, balanced class folders into `balancing/dataset_balanced/`.
* `data_analysis.ipynb` / `HAM10000_unified_analysis.ipynb`: Visual validation notebooks for post-balancing class distribution and sample inspection (Original vs. Augmented).
* `multiclass_analysis.ipynb`: Evaluation and diagnostic notebook for the 7-class multi-class model. It loads training history, generates learning curves, computes detailed classification reports, plots normalized confusion matrices, and evaluates model confidence and high-confidence misclassifications.
